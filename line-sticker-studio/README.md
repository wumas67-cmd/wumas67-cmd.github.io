# LINE 貼圖文字工作室

在網頁選擇主題，編輯 1–50 則貼圖文字，產生分批 AI 生圖提示詞，再將 5 × 4 綠幕大圖分割為透明 PNG。

## 功能

- 12 種主題：日常用語、打招呼、上班日常、常見回應、一個字、導遊帶團、團購專用、超商社群、情侶放閃、萌寵生活、家人互動篇、股票菜籃族
- 每種主題各有 50 則建議文字；可逐格修改或多行貼上，切換主題時保留各自的草稿
- 每批最多 20 張，自動產生 5 × 4 生圖提示詞，並帶入所選主題
- 可選擇讓 AI 繪字，或生成無字角色後在網頁疊字
- 圖片分割、綠幕去背強度、貼圖預覽、Main / Tab 封面
- 下載 PNG 與 README 組成的 ZIP

## 使用

開啟 [線上版本](https://wumas67-cmd.github.io/line-sticker-studio/)，或在此資料夾執行：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000/`。

圖片在瀏覽器本機處理，不會傳至伺服器；文字設定與各主題草稿儲存在該瀏覽器的 localStorage。上傳的圖片不會跨重新整理保存。

LINE 靜態貼圖單組僅接受 8、16、24、32 或 40 張。介面的 1–50 則是製作規劃數量；其他張數產生的 ZIP 是製作素材，需調整成合規張數才能送審。
