# LINE 貼圖文字工作室

在網頁選擇主題，編輯 1–50 則貼圖文字，產生分批 AI 生圖提示詞，再將 5 × 4 純 `#00FF00` 綠幕大圖分割為透明 PNG。

## 功能

- 15 種主題：日常用語、打招呼、上班日常、常見回應、一個字、導遊帶團、團購專用、超商社群、情侶放閃、萌寵生活、家人互動篇、股票菜籃族、正念減壓、佛道常用詞語、唯識學常用詞語
- 每種主題各有 50 則建議文字；切換主題只更換建議，已選文字與編號保持不變，可逐句或每次指定數量跨主題累加，最多 50 張
- 角色來源可選「參考上傳圖」或「自訂角色」；參考圖只在本機預覽，使用提示詞時須另外上傳給生圖工具
- 每批最多 20 張，自動產生 5 × 4 生圖提示詞，並帶入所選主題
- 可選擇讓 AI 繪字，或生成無字角色後在網頁疊字
- 圖片分割、綠幕去背與去綠邊、貼圖預覽、Main / Tab 封面
- 下載 PNG 與 README 組成的 ZIP

## 使用

開啟 [線上版本](https://wumas67-cmd.github.io/line-sticker-studio/)，或在此資料夾執行：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000/`。

圖片在瀏覽器本機處理，不會傳至伺服器；目前選取的貼圖文字與設定儲存在該瀏覽器的 localStorage。舊版每主題草稿仍保留在儲存資料中，更新時以最後使用的文字清單繼續編輯。上傳的圖片與角色參考圖不會跨重新整理保存。

LINE 靜態貼圖單組僅接受 8、16、24、32 或 40 張。介面的 1–50 則是製作規劃數量；其他張數產生的 ZIP 是製作素材，需調整成合規張數才能送審。

## 自動與手動切割

第 3 步支援 PNG、JPG、WebP 合圖。智慧切割預設純綠色背景，以連通區域找出貼圖；也可自行選擇自動、白色、自訂色或保留背景。白色角色請勿選白底去背。調整容差、合併間距及最小面積後重新偵測。

「去綠邊強度」預設 70：針對輪廓上與綠幕混色的像素估算透明度並移除綠色殘影，盡量保留白色毛髮。綠邊還在可提高強度，毛髮或文字變薄可降低；設定為 0 會關閉邊緣修正。智慧切割與固定 5 × 4 分批切割都提供此選項。固定分批切割只以 `#00FF00` 綠幕去背，保留角色白毛與白色配件。若原始圖片含真正的綠色主體，需逐張檢查並可能手動修圖。

手動模式支援自訂欄列（最多 50 格），拖曳分隔線調整整行／列，也可選取單框拖曳移動、拉右下角縮放、輸入 X／Y／寬／高、新增或刪除框。修改單框會解除網格連動。快速偵測模式可選少抓裝飾、平衡、多抓細節，並繼續調整背景容差、合併間距、最小面積和輸出留白。

按「套用切割並預覽」後可在模擬聊天室逐張切換貼圖、檢視左側或右側傳送效果，查看 Main／Tab 封面縮圖和送審前檢查，再下載單張 PNG 或 ZIP。設定起始編號 21 以上時，Main／Tab 預設關閉，ZIP 只含編號貼圖；可用核取方塊重新開啟。固定 5 × 4 分批模式也能取消 Main／Tab 匯出，且只有前 20 張顯示封面選擇鈕。

每次處理一張合圖，圖片與切框不跨重新整理保存。超過 5,000 萬像素拒絕讀取；最長邊超過 3000 px 會縮小處理。自動辨識適用透明或單色背景，複雜背景及黏連圖案需人工校正；與外部背景相通的同色內容仍可能被移除。原固定 5 × 4 分批工具位於折疊區。

核心回歸檢查：`node cut-core.test.cjs`。

## 貼圖文字設計

第一步可搜尋分類建議語句、隱藏已使用文字、避免重複、自動填滿空格，逐句增刪或用上下箭頭換順序。切換分類不重設貼圖清單；「加入未使用語句」按指定數量從當前分類累加，略過重複文字。可新增自訂文字並在一至五十句間調整數量。選擇某格後點建議語句可替換該格。

文字設計可選角色與文字比例（25/40/55/70%）、字體風格、顏色、背景與描邊，畫面即時預覽，並自動寫入每批生圖提示詞。使用「只生成無字角色」時，在第三步啟用網頁疊字即可套用文字設計；字體以瀏覽器可用字體近似呈現，無法保證生圖工具使用指定字型。設定與草稿儲存在瀏覽器中。

生圖提示詞預設為無白邊版本：角色、文字與裝飾外圍不加白色貼紙邊框、白色描邊或光暈；白色毛髮與物件原有白色仍保留。原始合圖固定為純 `#00FF00` 綠幕；如文字描邊選「白色」，生圖提示詞會改用深色細描邊以維持無白邊要求（網頁疊字的預覽設定仍照原選項）。

背景應為純 `#00FF00`、無漸層、陰影及雜點，所有主體外部與物件間的空隙也須為純綠色。若主體本身含綠色，請逐張檢查輸出。
