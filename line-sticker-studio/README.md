# LINE 貼圖文字工作室

可在網頁選擇與編輯 1–50 則貼圖文字，產生分批 AI 生圖提示詞，並把 5 × 4 綠幕大圖分割成透明 PNG。

## 功能

- 50 個常用文字選項、逐格編輯、多行貼上
- 每批最多 20 張，自動產生 5 × 4 生圖提示詞
- 可選擇讓 AI 繪字，或生成無字角色後在網頁疊字
- 圖片分割、綠幕去背強度、貼圖預覽、Main / Tab 封面
- 下載 PNG 與 README 組成的 ZIP

## 使用

開啟 `index.html` 即可使用。若要透過本機伺服器預覽，可在此資料夾執行：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000/`。

圖片在瀏覽器本機處理，不會傳至伺服器；文字設定儲存在該瀏覽器的 localStorage。上傳的圖片不會跨重新整理保存。

LINE 靜態貼圖單組僅接受 8、16、24、32 或 40 張。介面的 1–50 則是製作規劃數量；其他張數產生的 ZIP 是製作素材，需調整成合規張數才能送審。
