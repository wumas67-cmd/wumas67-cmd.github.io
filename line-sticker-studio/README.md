# LINE 貼圖文字工作室

在網頁選擇主題，編輯 1–50 則貼圖文字，產生分批 AI 生圖提示詞，再將 5 × 4 綠幕大圖分割為透明 PNG。

## 功能

- 12 種主題：日常用語、打招呼、上班日常、常見回應、一個字、導遊帶團、團購專用、超商社群、情侶放閃、萌寵生活、家人互動篇、股票菜籃族
- 每種主題各有 50 則建議文字；可逐格修改或多行貼上，切換主題時保留各自的草稿
- 每批最多 20 張，自動產生 5 × 4 生圖提示詞，並帶入所選主題
- 可選擇讓 AI 繪字，或生成無字角色後在網頁疊字
- 圖片分割、綠幕去背強度、貼圖預覽、Main / Tab 封面
- 下載 PNG 與 README 組成的 ZIP

## 使用

開啟 [線上版本](https://wumas67-cmd.github.io/line-sticker-studio/)，或在此資料夾執行：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000/`。

圖片在瀏覽器本機處理，不會傳至伺服器；文字設定與各主題草稿儲存在該瀏覽器的 localStorage。上傳的圖片不會跨重新整理保存。

LINE 靜態貼圖單組僅接受 8、16、24、32 或 40 張。介面的 1–50 則是製作規劃數量；其他張數產生的 ZIP 是製作素材，需調整成合規張數才能送審。

本工具是獨立開發的版本，與 Meiko 微課頻道及 LINE 無關。

## 自動與手動切割

第 3 步支援 PNG、JPG、WebP 合圖。自動模式從四邊估計背景，以連通區域找出貼圖；可指定綠色、白色、自訂色或保留背景。調整容差、合併間距及最小面積後重新偵測。

手動模式支援自訂欄列（最多 50 格），拖曳分隔線調整整行／列，也可選取單框拖曳移動、拉右下角縮放、輸入 X／Y／寬／高、新增或刪除框。修改單框會解除網格連動。按「套用切割並預覽」後下載單張 PNG 或 ZIP，可指定 Main、Tab 及起始編號。

每次處理一張合圖，圖片與切框不跨重新整理保存。超過 5,000 萬像素拒絕讀取；最長邊超過 3000 px 會縮小處理。自動辨識適用透明或單色背景，複雜背景及黏連圖案需人工校正；與外部背景相通的同色內容仍可能被移除。原固定 5 × 4 分批工具位於折疊區。

核心回歸檢查：`node cut-core.test.cjs`。

## 貼圖文字設計

第一步可搜尋分類建議語句、隱藏已使用文字、避免重複、自動填滿空格，逐句增刪或用上下箭頭換順序。可新增自訂文字並在一至五十句間調整數量。選擇某格後點建議語句可替換該格。

文字設計可選角色與文字比例（25/40/55/70%）、字體風格、顏色、背景與描邊，畫面即時預覽，並自動寫入每批生圖提示詞。使用「只生成無字角色」時，在第三步啟用網頁疊字即可套用文字設計；字體以瀏覽器可用字體近似呈現，無法保證生圖工具使用指定字型。設定與草稿儲存在瀏覽器中。
